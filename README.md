# Emby短视频客户端

简单直接的android客户端，像刷短视频一样刷emby视频。

面向 NAS Emby 的沉浸式 Android 短视频播放器（Android 8.0+，arm64-v8a）。

## 功能

- Media3/MediaCodec 硬解优先；硬解失败自动切换 LibVLC 软解，也可在设置中固定软解。
- 统一现代深色界面、圆角卡片、无衬线字体、播放器风格图标和涟漪按钮反馈。
- 设备方向稳定 800ms 且进入目标方向 ±18° 后才旋转，支持手动横竖屏和方向锁定。
- 双击播放/暂停；上下滑随机队列前后切换；左右滑采用指数曲线精细/快速调进度。
- 顶部 72dp/8% 安全区内开始的下滑不会切换视频，避免误触系统通知栏；进度滑动反馈严格限制在视频首尾范围内。
- 暂停时显示已播放/总时长和可拖动进度条；左右滑动时临时显示同一进度组件。
- 长按上、下半区分别临时变速，范围 1/8×–8×，松手恢复。
- 长按变速采用约 140ms 的低延迟识别，触发时提供轻微触觉反馈；一旦开始滑动会立即取消候选。
- 播放时沉浸式纯画面；暂停时显示标题、设置、横竖屏与锁定按钮。
- 每次进入时随机打乱所选媒体库/文件夹，后台并行完整预下载队列后两条，磁盘缓存上限 1GB。
- 自动播放可选，结尾可选下一条、暂停或循环本集。

## 构建

```powershell
./gradlew.bat testDebugUnitTest assembleDebug
```

首次启动进入设置，填写 Emby 地址、端口和账户。密码默认隐藏，可通过右侧眼睛按钮临时显示。点击“连接服务器并选择…”后，从媒体库开始逐级进入子目录，在目标位置点击“选择当前目录”，然后保存。

完整产品与验收要求见 `REQUIREMENTS.md`。

HTTP 明文访问已为家庭 NAS 场景启用。公网服务器建议使用 HTTPS。账户密码仅存于 Android 应用私有 SharedPreferences；Emby 流媒体 URL 使用访问令牌，因此不要分享播放器日志或完整 URL。

客户端对 NAS 媒体目录完全只读，不会创建 `.nfo`、封面、字幕或临时文件。预加载内容只写入 Android 应用私有 `cacheDir`。

## 播放控制

- **双击画面任意位置**：播放或暂停。
- **向上/向下滑动**：切换下一条或上一条视频；顶部安全区不会触发下滑切换，避免与 Android 通知栏手势冲突。
- **向左/向右滑动**：指数级调整播放进度。短距离为秒级精调，距离越长调整越快；目标进度始终限制在视频起点和终点之间。
- **长按画面上半区**：按设置中的“上半区倍速”临时播放，松手恢复正常速度。
- **长按画面下半区**：按设置中的“下半区倍速”临时播放，松手恢复正常速度。
- **拖动暂停界面的进度条**：直接定位播放位置，并显示已播放时长和总时长。
- **旋转设备**：稳定达到方向阈值后自动切换横竖屏；暂停后可用画面上的旋转和方向锁定图标手动控制。
- **暂停画面**：显示文件标题、进度、播放时长、设置、横竖屏切换和方向锁定按钮；播放时自动隐藏所有控件。

LibVLC 包含原生库，Debug APK 体积较大；工程仅打包 `arm64-v8a`，适用于骁龙 8 Gen 3 及更新设备。
